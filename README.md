# Sparks Foundation: GRIP Tasks

Machine learning and data analysis projects completed as part of **The Sparks Foundation's Graduate Rotational Internship Program (GRIP)**.

The internship involved working through a series of practical tasks covering supervised learning, unsupervised learning, exploratory data analysis, classification, predictive modeling, and data visualization.

## Tasks

| # | Project | Concepts |
|---|---|---|
| 01 | Student Score Prediction | Linear Regression, Supervised Learning |
| 02 | Iris Clustering | K-Means Clustering, Unsupervised Learning |
| 03 | Superstore Analysis | Exploratory Data Analysis, Business Analytics |
| 04 | Global Terrorism Analysis | Exploratory Data Analysis, Data Visualization |
| 05 | IPL Analysis | Exploratory Data Analysis, Sports Analytics |
| 06 | Iris Classification | Decision Trees, Classification |
| 07 | Stock Price Prediction | Time Series, Sentiment Analysis |
| 08 | COVID-19 Dashboard | Data Visualization, Tableau |

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Tableau
